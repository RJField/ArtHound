ArtHound UI — proposed design system

Direction: graphite + violet. The chrome (backgrounds, borders, labels) drops to near-neutral graphite so it recedes; the brand purple is reserved for actions, selection and focus — the things that should pull the eye. Baseline density tightens: 13px UI font, 30px table rows, tabular numerals everywhere numbers align.

3 · Controls — one radius (6px), two heights (28 / 32), four variants

Unified focus: every control gets the same 2px accent ring (--ring). Kills the current border-vs-ring-vs-undefined-var mix. Tab to try it.

Display 20/600 — page titles (one per page, max)
